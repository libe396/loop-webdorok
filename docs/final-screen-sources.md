- 화면은 Figma 원본 export를 WebP quality 95로 인코딩. 무브바디는 2배수 export 반환 누락으로 Figma screenshot 원본 402×824 사용. 나머지 10장은 2배수 PNG에서 변환.
- 목업: 같은 섹션의 `목업` 프레임 `3029:55057` 안 `iPhone 17` 인스턴스 `2953:27047`. 이미지 해시 `a1529de8920008b7dec0c58a24d4841fefe0560a` 원본 1350×2760을 lossless WebP로 보관.
- Figma 인스턴스 화면 402×874, 외곽 렌더 영역 450×920. 화면 오프셋 x24/y23을 CSS 비율 토큰으로 그대로 적용. 별도 노치 도형을 만들지 않는다.
- 화면의 가로세로 비율을 유지하고, 긴 화면은 폰 내부에서 세로 스크롤한다. 프레임 이미지는 포인터 입력을 막지 않는다.
- `src/assets/screens/final/`에서 Vite가 콘텐츠 해시를 붙여 캐시를 갱신한다. `src/data/screens.js`가 11개 화면을 연결한다.
