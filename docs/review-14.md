## 시각 검증 및 스크롤 길이

내장 브라우저는 초기화 오류가 있었으나 별도 Chromium 헤드리스 브라우저로 검증했습니다. 모바일은 390×844 에뮬레이션이며 실제 기기 검증은 아닙니다.

| 뷰포트 | 수정 전 Landing 전체 높이 | 수정 후 | 감소 |
|---|---:|---:|---:|
| 1920×1080 | 21,918px | 17,818px | 4,100px (18.7%) |
| 390×844 | 17,220px | 13,425px | 3,795px (22.0%) |

- 폰트와 지연 로드 이미지를 로드한 뒤 document.documentElement.scrollHeight로 측정. 수정 전은 작업 시작 HEAD의 임시 복사본.
- S07 렌더 없음, 프로토타입 CTA 3개 없음, GNB 결과물 메뉴 없음, S08 결과물 행 SPAN 확인.
- S06 position: relative 확인. 섹션 안에서 wheel 500 입력에 페이지가 약 496px 이동하여 핀 없이 지나감.
- S05 데스크톱에서 s0 → a1 → a2 → a3 → a4 → s9 6장 전환 확인. 모바일 6장 가로 스크롤 확인.
- S09 모바일 워드마크 4개 2×2 캡처 확인.
- 라이트박스 원본 1920 요청, 좌우 이동, ESC/배경 클릭 닫기, 랜딩 복귀 확인.
- 근거 딥링크는 라우트 전환 시 Lenis 높이 갱신을 추가해 수정. r071은 데스크톱 화면 상단 120px, 모바일 180px에 도착 확인.
- 런타임 pageerror 없음. 전체 캡처는 /tmp/loop14-captures/에 보관.
- public/og.png: sharp + Wanted Sans SemiBold + 기존 워드마크·리본, 1200×630. 이미지 직접 확인.
